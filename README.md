# Cybersecurity_Labs

Hands-on cybersecurity and pentesting labs (Kali, Metasploitable, Wireshark, Nmap).
All labs run on isolated virtual machines (VirtualBox, Host-only network) that I own.

## Labs

| # | Lab | Tools | Status |
|---|-----|-------|--------|
| 01 | [netcat_wireshark](2026_lab_01_netcat_wireshark/) | Netcat, Wireshark, Nmap, Metasploit | In progress |

## Environment

- Attacker: Kali Linux (VM)
- Target: Metasploitable 2 (VM)
- Network: VirtualBox Host-only (isolated, no internet exposure)

## Structure

Each lab lives in its own folder named `YYYY_lab_NN_topic` and contains notes, captures, and a short report.
